# Vizualiza-n-a-rezerva-n-syst-m-kina-s-konstrukt-rem-s-l-
Vytvořte v prostředí Visual Studio (jazyk C#) desktopovou aplikaci pro Windows Forms s verzováním na GitHubu. Aplikace bude sloužit jako interaktivní rezervační systém vstupenek pro kina, divadla či kinosály s integrovaným vizuálním navrhářem sedadel. Uživatel (administrátor) bude moci na plátno nakreslit a nakonfigurovat rozložení sálu (řady, sedadla, uličky, VIP zóny, bezbariérová místa), definovat jednotlivá představení a nastavit ceník. Zákaznická část rozhraní nabídne přehledné visualizované sály s reálným stavem obsazenosti, interaktivní výběr sedadel myší, automatické dohledávání nejlepších sousedních volných míst pro skupiny (algoritmus pro vyhledání $N$ volných sedadel vedle sebe) a výpočet celkové ceny. Veškerá data (konfigurace sálů, program představení a aktivní rezervace) se budou ukládat a načítat ze strukturovaných souborů ve formátu JSON nebo XML a aplikace bude podporovat export potvrzených vstupenek do formátu PNG nebo HTML.
